# Piccolo Mondo — anteprime

Bozze del nuovo sito di **Piccolo Mondo**, Arbia (Siena).

`index.html` è la galleria: elenca tutte le proposte e linka a ciascuna.
Ogni cartella numerata è un sito statico completo e indipendente
(`index.html`, `style.css`, `app.js`, `data.js`, `fonts/`).

- Nessuna dipendenza esterna: font inclusi localmente, nessuna richiesta di rete.
- Percorsi tutti relativi, quindi funziona sotto qualsiasi sottocartella.
- Menu bilingue IT/EN (le descrizioni inglesi dei piatti sono ancora da scrivere
  e ricadono sull'italiano).

I dati del menu vivono in `data.js`, identico in ogni cartella.
